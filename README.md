## Introducing Today's Project!

### What is Amazon Aurora?

Amazon Aurora is a fully managed, MySQL- and PostgreSQL-compatible relational database service and it is useful because it provides high performance, availability, and scalability without requiring you to manage the underlying database infrastructure.

### How I used Amazon Aurora in this project

In today's project, I used Amazon Aurora to create a highly available, scalable relational database for my application and connect it with an EC2 instance.

### One thing I didn't expect in this project was...

One thing I didn't expect in this project was the AWS Free Plan restrictions, which prevented me from creating an Aurora MySQL database and required me to use Aurora PostgreSQL with Express configuration instead.

### This project took me...

Took about 1.5 hours because of Free Tier Plan problem which I was facing
